LOCAL FARMERS SUPPORT PORTAL (HTML + CSS only)

How to run: unzip, then double-click index.html. No server or internet needed.

Files
  index.html    Home
  farmers.html  Farmer profiles (browse by village)
  produce.html  Produce listings (quantity, price, availability, browse by category)
  order.html    Request form + request status examples
  ratings.html  Reviews and rate-a-farmer form
  join.html     Farmer registration + publish produce forms
  admin.html    Farmer verification
  thanks.html   Page shown after any form is submitted
  style.css     The only stylesheet
  images/hero.png

Note: there is no JavaScript, so forms only open thanks.html. Data is not saved.
Sample data (names, villages, prices) can be changed directly in the HTML files.
